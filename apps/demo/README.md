# demo

A Vite app that shows the `v-haptic` directive, the `useHaptics` composable and the plugin options.

Run it from the repository root. Turborepo builds the library first, then serves this app.

```sh
pnpm install
pnpm dev
```

Scan the QR code in the terminal to open the page on a phone. Haptics need a touch device: Android Chrome, or iOS Safari 18 and later.
