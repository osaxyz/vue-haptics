# v3.0.0

## Breaking Changes

- Vue 3 向けに一から書き直した
  - `useHaptic` と `triggerHaptic` を廃止し、`useHaptics` と `trigger` に置き換えた
  - 既定の長さを 5ms から 10ms に変更した
  - `peerDependencies` を `vue ^3.3.0` に変更した
- fork ではない新しいリポジトリとして作り直した。旧リポジトリは osaxyz/vue-haptics-legacy に移して archive した

## Features

- `v-haptic` ディレクティブを追加した。値でパターンを指定し、`false` で無効化、引数でイベント名を変える
- `haptic()` を追加した。コンポーネントの外からも呼べる
- `createHaptics()` プラグインを追加した。ディレクティブの登録と既定値、全体の無効化を設定できる
- `isHapticsSupported()` と `useHaptics().isSupported` を追加した
- 配列のパターンに対応した。iOS では "on" の区間ごとに1回鳴らす

## Fixes

- 隠し switch 要素をページ全体で1組だけ作るようにした。v2 はコンポーネントごとに同じ id の要素を追加していた
- 隠し switch 要素のクリックがアプリのクリックハンドラに伝わらないようにした
- UA 判定をやめ、`navigator.vibrate` の有無で経路を選ぶようにした。iPadOS を取りこぼさない
